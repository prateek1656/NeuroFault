# Simulator bug catalogue

Errors in the simulation stack that changed reported numbers, found while building Paper A and fixed or documented. This expands `tab:bugs` in `papers/controller/main.tex` ("Simulator pitfalls with a stored measurement"). It lists only entries with a stored measurement, as the paper does.

How to read it:

- **Effect** is the measured change in a reported number, quoted from the paper.
- **Fix** is the code or protocol change that resolved the problem, taken from the archived development history (commit messages and diffs) and the paper. Where a problem was documented but not fixed, the entry says so.
- **Evidence** says what check backs the effect. Details live in the audit outputs in `results/derived/` (`classical_claims.csv`, `pair_audit.csv`, `dup_audit.csv`, `claims.csv`) and the scripts that write them (`scripts/analysis/audit_classical.py`, `audit_runs.py`, `derive_paper_numbers.py`). Those audit scripts need the raw private run archive, so only their outputs ship.
- Run names in the shipped results may predate a fix. Runs made before the DAC fix are exploratory and are not used for any headline number. `results/MANIFEST.md` lists which run families predate which fix.

| B8 | Baseline under-tuning | Burst learning rate at the edge of the sweep grid. | Retraining-only gained +44.7 points when tuned, in 3 of 3 seeds. ## Other errors, not quantified

The development history also records a training step that never reached the analog core, and a backend whose forward pass ignored conductance. The paper does not report effect sizes for these, because a stored probe is missing. They are not used in the papers.

## Lessons the paper draws

- Converter details dominate accuracy. A fixed input-clipping range collapsed the analog network.
- Repair logic needs its own tests. Writers must be tested together with the optimizer.
- Comparisons need hygiene: matched compute, tuned rates, paired fault maps, and no best-of-N reporting.
- The same seed gives different fault maps on different GPU models. Pooled seeds in the main test mix two GPU models.
